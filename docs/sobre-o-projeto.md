# Sobre o Projeto

Este repositório é usado na disciplina **DevOps I** do curso de Bacharelado em Ciência da Computação da Univértix.

## Objetivo

Praticar o **Git Flow** de forma colaborativa: cada aluno cria uma `feature branch` a partir de `develop`, adiciona seu perfil e integra via merge com `--no-ff`.

## Branches ativas

| Branch | Propósito |
|--------|-----------|
| `main` | Código estável — releases oficiais |
| `develop` | Integração — onde features são mescladas |

## Turma

Bacharelado em Ciência da Computação — 2026
